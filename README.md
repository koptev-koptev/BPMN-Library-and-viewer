# 📊 BPMN Library and viewer

**BPMN Library and viewer** — это веб-приложение для хранения, просмотра и обмена диаграммами BPMN 2.0. Работает полностью в браузере без бекэнда.

## ✨ Возможности

### 📋 Библиотека схем
- Список всех загруженных BPMN-диаграмм с поиском
- Сортировка по алфавиту и по дате добавления
- Фильтрация по тегам
- Переименование схем прямо в списке
- Массовое выделение схем для удаления или простановки тегов

### 🖼️ Просмотр диаграмм
- Отображение `.bpmn` файлов средствами bpmn-js
- Изменение масштаба (кнопки, ползунок, Ctrl + колесо мыши)
- Сдвиг по горизонтали (ползунок, стрелки, Shift + колесо, перетаскивание мышью)
- Быстрые режимы «По окну» и «По высоте»
- Полноэкранный просмотр

### 📥 Импорт схем
- Добавление одного или нескольких `.bpmn` файлов за раз
- Перетаскивание файлов прямо в окно браузера
- Проверка корректности файла (BPMN 2.0 XML)
- Автоматическое исключение дубликатов
- Отчёт по итогам импорта

### 🏷️ Теги
- Присвоение тегов отдельной схеме или сразу нескольким
- Фильтрация списка по тегам

### 💾 Хранение и обмен
- Хранение всех схем локально в браузере (IndexedDB)
- Экспорт всей базы в один JSON-файл
- Импорт JSON-базы — новые схемы добавляются к уже имеющимся
- Экспорт отдельной схемы обратно в `.bpmn` для редактирования
- Ограничение суммарного объёма базы — 1 ГБ, с индикатором занятой памяти

### 🌗 Интерфейс
- Переключатель светлой и тёмной темы
- Скрытие панели со списком схем для увеличения области просмотра

## 📖 Руководство пользователя

### Добавление схем
1. Нажмите **"+ Добавить схемы"**
2. В диалоге выбора файлов отметьте один или несколько `.bpmn` файлов (`Ctrl`/`Shift` или `Ctrl+A`)
3. Дождитесь окончания импорта и проверьте отчёт, если были пропущенные файлы

### Просмотр схемы
1. Выберите схему в списке слева
2. Настройте масштаб и положение инструментами на панели сверху
3. При необходимости откройте схему на весь экран кнопкой "⛶ На весь экран"

### Переименование и теги
1. Нажмите ✎ у схемы в списке или в шапке просмотра — для переименования
2. Нажмите 🏷 у схемы или "+ тег" в области просмотра — для добавления тегов
3. Для группового добавления тегов отметьте несколько схем галочками и нажмите "Добавить тег"

### Экспорт и импорт базы
- **Экспорт**: кнопка "⬇ Экспорт базы (JSON)" — скачается файл со всеми схемами
- **Импорт**: кнопка "⬆ Импорт базы (JSON)" — выберите ранее сохранённый файл, схемы добавятся к уже имеющимся
- **Экспорт одной схемы**: кнопка "⬇ Скачать .bpmn" — для открытия в редакторе диаграмм

## 🎨 Интерфейс

### Список схем
Каждая строка списка содержит:
- Название и дату добавления
- Размер файла
- Теги
- Кнопки переименования, тегов, экспорта и удаления

### Область просмотра
- Название схемы, теги и дата добавления в шапке
- Панель масштаба и сдвига под шапкой
- Сама диаграмма на остальной площади окна

### Индикатор памяти
Под списком схем отображается занятый объём от лимита в 1 ГБ:

| Заполнение | Цвет |
|------------|------|
| до 70% | Зелёный |
| 70–90% | Жёлтый |
| свыше 90% | Красный |

## ⚙️ Технические детали

### Технологии
- **HTML5** — структура страницы
- **bpmn-js** (CDN) — отображение BPMN-диаграмм
- **Vanilla JavaScript** — логика приложения
- **IndexedDB** — хранение схем в браузере
- **localStorage** — настройки темы и сортировки
